# Software Engineering for Pre-Trained Models

A research program of the [Duality Lab](https://davisjam.github.io/), led by
James C. Davis at Purdue University.

Reuse, integration, interoperability, evolution, security, and engineering of pre-trained models as software artifacts.

This repository hosts the program's project site, published at
<https://davisjam.github.io/software-engineering-pre-trained-models/>.

The site is under construction.
